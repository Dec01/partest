# Post-generation agent playbook (G6)

What to do **after** `partest-gen from-openapi` / `init-ui` until the suite is useful.

---

## 0. Preconditions

```bash
# greenfield API + optional UI
partest-gen from-openapi ./my-suite --file openapi.yaml --depth p1 --force --with-ui
# or add UI later
partest-gen init-ui ./my-suite --force

cd my-suite
python -m venv .venv && source .venv/bin/activate  # or Windows equivalent
pip install -r requirements/api.txt
# UI:
pip install -r requirements/ui.txt && playwright install chromium
cp env.example .env
```

**Never commit** real passwords, private stand URLs, or filled `roles.py` secrets.

---

## 1. Read generated maps (order matters)

| Artifact | Why |
|----------|-----|
| `.partest/openapi_summary.md` | ops × subtype × required P1 |
| `.partest/suite_ir.json` | machine IR if you script |
| `src/api/tests/<tag>/P1_CHECKLIST.md` | per-tag backlog (G4) |
| `src/api/resources/endpoints/paths.py` | path constants |
| `docs/wiki/howto/ui.md` | UI isolation + baselines (if G5) |

Prioritize **impact**: auth / money / PII writes before catalog GETs.

---

## 2. Wire environment & auth (API)

1. `.env` — `BASE_URL`, optional Keycloak (`KEYCLOAK_*`).
2. `src/api/resources/rbac/roles.py` — `ALL_ROLES` + `get_role_credentials(role)` from env.
3. Uncomment `TokenManager` fixtures in `src/api/tests/conftest.py` when roles exist.
4. Confirm: `pytest src/api/tests/test_smoke_health.py -q` (or health default) hits the stand.

Isolation rule: **UI tests must not import** API swagger session / `confpartest` coverage loaders.

---

## 3. API implementation loop (one tag or endpoint at a time)

For each high-impact operation:

1. Confirm **subtype** in summary (or `classify_endpoint`).
2. Open matching stubs under `src/api/tests/<tag>/`:
   - `test_*_default.py`, `*_permissions`, `*_new_object` / `*_update_object`, …
3. **Unskip** only when seed data / path params are ready.
4. Fill TODOs:
   - `add_url1` / seed ids
   - payload FK via `payload.set_payload_field(...)`
   - `ah.check_*` / value asserts after status + `validate_model`
5. Always pass **`type=`** for permissions / new / update / elements / extra / env / benchmark.
6. Create/update → vertical TC (`request_new_object` / `request_update_object`), not only default on seed.
7. Cleanup: prefer `TrackingApiClient` + registry (already wired in API conftest).

**Depth of asserts:** status → schema (`validate_model`) → values. Status-only is not “covered”.

Transport IncorrectBody (keep on ApiClient):

```python
content=b'{"a":', content_type="application/json", type=types.request_incorrect_body
```

Do **not** use raw httpx for suite coverage calls.

---

## 4. Measure & close gaps

```bash
pytest src/api/tests -q --domain "$BASE_URL"
# last (or dedicated job): coverage report
pytest src/api/tests/test_zorro.py -q
```

From `zorro` / `coverage_report.html`:

- `missing_p1` per endpoint → next backlog
- Prefer empty missing_p1 on critical writes before polishing P3 on catalogs

`partest-gen sync-openapi ./my-suite --depth p1` after OpenAPI changes:

- Overwrites only files with `AUTO-GENERATED by partest-gen` banner (unless `--force`)
- Re-check hand-edited tests still import

---

## 5. UI loop (orthogonal to API depth)

1. `FRONTEND_URL` / login env in `.env`.
2. Implement `LoginPage` + app shell selectors (`data-testid` preferred).
3. `fixtures/api_seed.py` — create data via API **without** loading OpenAPI into UI conftest.
4. Smoke → auth → rbac → visual.
5. Baselines:

```bash
# library CLI (1.4+)
python -m partest.ui.capture_baselines --out src/ui/baselines/reference \
  --frontend-url "$FRONTEND_URL" --scenes src/ui/tools/scenes.json

# or consumer wrapper
python -m src.ui.tools.capture_baselines
```

- Commit `baselines/reference/`; keep `actual/` + `diff/` gitignored.
- Visual tests use `compare_images` / `partest.ui` freeze helpers.

---

## 6. Definition of done (suite slice)

- [ ] `.env` + roles work on target stand
- [ ] P1 TC for chosen endpoints implemented with correct `type=`
- [ ] Vertical TC for create/update paths
- [ ] Status + schema + meaningful value asserts on positives
- [ ] `zorro` missing_p1 empty for those endpoints
- [ ] Created resources cleaned up
- [ ] UI (if any): smoke green; baselines only after stable selectors
- [ ] No secrets / private URLs in git

---

## 7. Agent anti-patterns

| Don't | Do |
|-------|-----|
| Commit Keycloak passwords | env + `roles.py` readers |
| Remove `type=` early | keep until inference ≥0.99 for that case |
| Put product paths into `partest` library | keep in generated `paths.py` / consumer |
| Load OpenAPI in `src/ui/conftest` | isolate UI session |
| Polish P3 everywhere first | impact × P1 first |
| Bypass ApiClient with raw httpx | lose coverage counters |
| `--force` sync over hand tests blindly | read banner policy |

---

## 8. Quick commands cheat sheet

```bash
partest-gen from-openapi ./suite --file openapi.yaml --depth p1 --force --with-ui
partest-gen sync-openapi ./suite --depth p1
partest-gen dump-ir openapi.yaml -o .partest/suite_ir.json
partest-gen init-ui ./suite --force

pytest src/api/tests --collect-only -q    # import smoke
pytest src/api/tests -q
pytest src/ui/tests -q -m ui_smoke

python -m partest.ui.capture_baselines --dry-run --scenes scenes.json
```
